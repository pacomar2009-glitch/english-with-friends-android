# English with Friends · App Android

Aprende inglés con tus propios vídeos: sesión diaria, práctica, conversación con tutor de IA y seguimiento de progreso.

## Descargar

**[⬇ Descargar english-with-friends.apk](https://github.com/pacomar2009-glitch/english-with-friends-android/releases/latest/download/english-with-friends.apk)**

Funciona en móviles y tablets Android 7.0 o superior.

## Instalar

1. Abre el enlace de arriba desde tu móvil o tablet y descarga el archivo.
2. Al abrirlo, Android pedirá permiso para **instalar apps desconocidas** desde tu navegador (o gestor de archivos). Actívalo solo para esta instalación.
3. Pulsa **Instalar** y abre **English with Friends**.

## Primer uso

La IA (ejercicios generados, corrección y voz) usa tu propia clave de [OpenRouter](https://openrouter.ai/keys). Se guarda solo en tu dispositivo: **Ajustes → Clave de OpenRouter**. Sin clave, el resto de la app funciona.
